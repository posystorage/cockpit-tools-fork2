# v1.3.69 合并后二次审计

审计日期：2026-10-16。基线为 fork 800fd63b 与上游 11aeacb4 的合并提交 b5aad8df。
本报告审计六组 fork 功能及发布边界；不把整仓编译或字符串断言当作真实客户端验收。

## 本轮发现与修正

### P2：删除后重新导入账号，普通页窗口用量可能缺失

request_logs 查询只使用本地 account_id；查询参数中的 official_account_id、account_email 未参与匹配。
这不是本次文本合并新引入的回退，800fd63b 已有同样缺口，但与维护要求不一致。
现保留本地 ID 直接匹配；历史别名必须同时满足官方 ID 与非空邮箱一致，邮箱忽略大小写。
支持旧日志把官方 ID 写入 account_id 的历史格式。共享工作区仅官方 ID 相同不能合并。
同一行同时命中本地和历史别名时只累加一次，不修改原始日志、账号或 API 页历史记录。
新增数据库回归覆盖重导入、共享团队不同邮箱、缺少邮箱、错误官方 ID、本地 ID 优先。

### P2：Go 进程退出后可能残留“处理中”观测

原代码没有在 stdout 结束时清理未收到 usage 的 auth_selected 请求，可能等待 30 分钟过期。
现每条进程 stdout 独立追踪尚未完成的请求 ID，在 EOF/读错误后结束这些活动。
usage 会移除对应追踪；清理只按精确 ID 执行，不清空全局状态，不影响 Rust 或其他实例的请求。
这只修正活动展示，不伪造 usage、成功率或费用。新增并发隔离回归。
硬终止整个主程序后内存本身消失；正常进程退出、引擎切换仍由现有生命周期负责。

### P2：默认价格迁移的后台重算目标缺少已退役模型

冷加载重算原先只列当前价格预设与保留的自定义项，清理后的历史模型覆盖不在目标集中。
现冷迁移同时加入上游 HISTORICAL_CODEX_MODEL_PRICE_BOOK 的模型 ID，交由已有队列去重和重算。
未复制维护独立价格数值，不恢复 GPT-5.5 请求选项；历史日志仍可按上游历史价计费。

### P3：Rust 音频/实时请求运行中显示为文本活动

辅助端点 RequestTracker 默认 operation=text；完成统计会按 endpoint 修正，但运行中活动回调没有 endpoint。
现 HTTP 与 WebSocket 辅助入口在授权/选路前设定 operation；独立 alpha/search 保留 text，其他辅助操作为 other。
保持请求传输、配额和错误处理流程。新增端点分类回归。

### 文档与测试兼容性

更新维护指南第 9.2 节和测智说明为七请求模型，移除 GPT-5.5，保留 GPT-6.1 Sol。
Go 图片协议 golden 比较在比较前规范 CRLF，避免 Windows Git 换行造成假失败；协议内容仍逐字节比较。
未删除参考库历史校准数据，未修改上游通用模型兼容测试中的 GPT-5.5 历史样本。

真实 OAuth/API 请求、Codex Desktop 当前 DOM 适配、双引擎在线切换、Windows/macOS 安装包均尚未做运行验收。
静态审查未发现继续阻塞代码合并的显式冲突；要把 Rust 标记为可替代 Go 的稳定引擎，仍需在可运行环境完成这些验收。
