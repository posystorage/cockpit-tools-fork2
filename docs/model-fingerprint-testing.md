# 模型指纹测试

入口按钮统一为“指纹测智”：账号概览页位于“鹈鹕测智”按钮紧邻左侧；模型供应商页位于“一键测试”按钮紧邻左侧。两处均使用原有批量操作区，不在顶部工具栏重复放置入口。

- 请求模型：gpt-5.5、gpt-5.6-sol/terra/luna、gpt-6-astra/sol/luna。
- 首次默认勾选 gpt-5.6-sol、gpt-6-sol、gpt-6-astra；之后记忆模型选择，包括全部取消。
- 首次不勾选账号；开始测试后记忆本次实际使用的账号／API Key。
- OAuth 账号、独立 API Key 账号、模型供应商中的各个 API Key 均可选择；相同上游和 Key 去重。
- 按账号／上游 × 请求模型生成组合；每组采样 1、2 或 3 次，默认 3。
- 最大并行数 1–10，默认 3；同一组合内顺序采样。OAuth 请求也受原有账号调度器限制。
- 额度、鉴权、网络错误不自动重试，不切换目标账号或请求模型。
- 仅部分回答通过数字序列完整性校验时标为“部分完成”，不会当作完整测试成功。
- 停止按钮取消正在进行的 HTTP 请求并停止后续组合；最小化／关闭面板继续后台测试。

OAuth 请求通过现有 API Service 的指定账号路由；API 上游按保存的 Responses 或
Chat Completions 协议直接请求，不改变账号、路由或供应商配置。实际开始测试会消耗额度。
设置记忆仅包含目标标识、模型和采样参数，不保存 API Key；测试结果仅保留在本次应用会话中。

算法与参考库来自 ModelTrace，固定来源版本和 MIT 许可见 src/vendor/modeltrace/README.md。
参考库和分析代码随应用打包，分析在本地进行，不上传凭据或回答到 ModelTrace。
候选概率是参考库内的统计归因，不是模型身份的确定证明；返回的 model 字段只作单独展示。

本版不修改额度耗尽提示窗口隐藏功能。
