# 模型指纹测试

入口按钮统一为“指纹测智”：账号概览页位于“鹈鹕测智”按钮紧邻左侧；模型供应商页位于“一键测试”按钮紧邻左侧。两处均使用原有批量操作区，不在顶部工具栏重复放置入口。

- 请求模型：gpt-5.6-sol/terra/luna、gpt-6-astra/sol/luna、gpt-6.1-sol。
- 首次默认勾选 gpt-5.6-sol、gpt-6-sol、gpt-6-astra；之后记忆模型选择，包括全部取消。
- 首次不勾选账号；开始测试后记忆本次实际使用的账号／API Key。
- OAuth 账号、独立 API Key 账号、模型供应商中的各个 API Key 均可选择；相同上游、Key、协议和鉴权方式去重。
- 按账号／上游 × 请求模型生成组合；每组采样 1、2 或 3 次，默认 3。
- 最大并行数 1–10，默认 3；同一组合内顺序采样。OAuth 请求也受原有账号调度器限制。
- 额度、鉴权、网络错误不自动重试，不切换目标账号或请求模型。
- 仅部分回答通过数字序列完整性校验时标为“部分完成”，不会当作完整测试成功。
- 停止按钮取消正在进行的 HTTP 请求并停止后续组合；最小化／关闭面板继续后台测试。

自 v1.3.63 合并起，OAuth 请求复用上游独立账号准备与直连代理路径，不启动 API Service；
API 上游按保存的 Responses、Chat Completions 或 Anthropic 协议和显式鉴权方式直接请求，
不改变账号、路由或供应商配置。Anthropic 只接收正常结束的文本，截断、拒答或工具调用不作为完整样本。
实际开始测试会消耗额度。
设置记忆仅包含目标标识、模型和采样参数，不保存 API Key；测试结果仅保留在本次应用会话中。
供应商已删除 Key 的排除记录也适用于关联的 API 账号，避免删除后从指纹列表重新出现。

算法与参考库来自 ModelTrace，固定来源版本和 MIT 许可见 src/vendor/modeltrace/README.md。
当前固定提交为 `6cd4a8ff0f3f4e49d6d6969dd2fbadfa1569fde2`；统一参考库包含 18 个候选，
新增 Claude Sonnet 5.5 和 Haiku 5.5，并整体保留对应的 robust 空间及 1/2/3 样本校准。
请求选项仍为上述七个模型，`gpt-5.5` 不作为请求选项；参考候选不裁剪或改名。
参考库和分析代码随应用打包，分析在本地进行，不上传凭据或回答到 ModelTrace。
候选概率是参考库内的统计归因，不是模型身份的确定证明；返回的 model 字段只作单独展示。
gpt-6.1-sol 可作为请求模型选择；当前固定参考库尚无 GPT-6.1 Sol 或 Terra 指纹，分析仍在既有候选内进行，不新增未经校准的参考数据。
未集成 ModelTrace Guard 任务监测插件、hooks 或自动额外采样。

本版不修改额度耗尽提示窗口隐藏功能。
